# 网络启动（NetBoot）

把一台已 Root 的 Android 手机变成**装机服务器**：给同一局域网内的电脑提供 PXE 网络启动，
或者把自己变成一个**只读 USB 安装盘**。

---

## 能做什么

- **PXE 网络启动**：手机与电脑接同一个局域网，用 ProxyDHCP / DHCP + TFTP + HTTP Boot 引导 PC。
- **USB 安装盘**：把手机里的镜像临时映射成只读 USB 存储，插数据线给 PC 引导。
- **镜像管理**：下载微软官方 Windows ISO、导入本地 ISO、多连接断点续传、SHA-256 校验。

流程：**获取镜像 → 选 PXE 或 USB → 启动服务 → 使用 → 停止并恢复手机状态**。

---

## 使用前提

1. **手机能使用Root权限，且 KernelSU 已授权本应用使用 `su`**
2. **Android 8.0 及以上。**
3. **PXE**：手机与电脑在同一局域网，且路由器已关闭客户端隔离。
4. **USB**：一根数据线，PC 能从 USB 启动。

---

## 快速上手

### 第一步：拿一个镜像

打开「镜像」页：

- **官方下载**：选 Windows 版本（10 / 11）、语言（简体中文 / 英语）、架构，点「官方下载」。
  下载链接由微软官方接口实时获取，过期会自动刷新。
- **导入 ISO**：点「导入 ISO」，用文件选择器选一个已有的镜像。

下载可暂停 / 继续 / 取消，取消时可以选择是否保留已下载的部分。完成后应用会计算 SHA-256 并把
状态置为「就绪」。**只有「就绪」的镜像才能用于 PXE 或 USB。**

### 第二步：选择启动方式

**A. PXE 网络启动**

1. 进「PXE」页，选择**网络接口**（手机当前联网的那个）。
2. **DHCP 模式**选 `ProxyDHCP`：路由器继续分配 IP，手机只提供启动文件。家庭网络用这个最省事，
3. 选择 **TFTP 启动文件**：点按列表中的文件即可选中。
4. 需要时编辑 **iPXE 脚本**，改完点「保存配置」才会长期保留。
5. 点「启动 PXE」，然后在 PC 的启动菜单里选网络启动。

**B. USB 安装盘**

1. 在「镜像」页找到就绪的镜像，点它右侧的 USB 图标。
2. 确认后会开始映射，需要转换的镜像会先制作安装盘，界面显示进度且**可以取消**，
   原始 ISO 不会被改动。
3. PC 会把它识别为一个只读 U 盘或光驱，从它启动即可。
4. **用完请停止 USB**，等状态恢复后再拔线。

### 第三步：收尾

结束后在首页或对应页面点「停止 PXE」/「停止 USB」。应用会关闭 DHCP/TFTP/HTTP 服务、解绑 USB
并恢复手机原来的 USB 配置。若提示 USB 恢复失败，重新插拔数据线或重启手机即可。

---

## 安全说明

- 应用只读写自己的私有目录：数据库、配置、日志、临时文件和你导入的镜像。
- USB 部分只操作内核中的 USB gadget 配置（内存态，重启自动复位），不碰任何真实分区；
  映射给 PC 的介质始终只读，PC 无法写坏手机。
- 应用不会刷写分区、不会关闭 SELinux / AVB、不会改启动镜像或安装内核模块。
- 日志不记录临时下载链接等敏感信息，可在「设置 → 运行日志」查看、复制或导出。

## 构建与安装

```bash
# 需要：JDK 17+、Android SDK、NDK 28.2.13676358、Go 1.27
./gradlew testDebugUnitTest lintRelease        # 单元测试 + Lint
./gradlew assembleRelease                      # 发布构建
./gradlew assembleDebug -PnetbootAbis=arm64-v8a,armeabi-v7a,x86_64   # 含模拟器 ABI
```

发布产物按 ABI 拆分，同时附带一个通用 APK，按手机架构选择即可（多数手机用 `arm64-v8a`；
不确定就用 universal APK）。Go 核心会在构建时自动编译并校验 ABI，无需手工执行 gomobile。
需要真机才能跑的测试用 `./gradlew connectedDebugAndroidTest`。

开发规范、安全边界与发布流程见 [AGENTS.md](AGENTS.md)
